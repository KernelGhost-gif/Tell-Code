# TellC documentation

TellC is an experimental, strongly typed compiler that shares the Tell
project's sentence-oriented syntax goals but has its own language subset.

- BUILDING.md explains Linux, Intel macOS, and Apple silicon build modes.
- TESTING.md documents the automated tests and how to add regressions.
- ARCHITECTURE.md describes parsing, LLVM code generation, and native linking.

Start with the platform build guide before changing the LLVM or LLD linkage.
